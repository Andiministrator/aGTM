Callbacks

Definiere eigene JavaScript-Funktionen, die bei bestimmten Events ausgeführt werden.

consent_callback

Wird ausgeführt wenn Consent geprüft oder aktualisiert wird.

Parameter: action ('init' oder 'update')

JavaScript

inject_callback

Wird ausgeführt wenn ein GTM-Container injiziert wird.

Parameter: containerId (z.B. 'GTM-ABC123')

JavaScript

fire_callback

Wird ausgeführt wenn ein Event über aGTM.f.fire() gesendet wird.

Parameter: eventData (das Event-Objekt)

JavaScript

optout_callback

Wird ausgeführt wenn ein User das Opt-out nutzt.

Kein Parameter. Wird aufgerufen wenn Opt-out Cookie gesetzt wird.

JavaScript
